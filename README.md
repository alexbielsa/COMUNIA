# Comunia · Gestión de comunidades de propietarios

Web app estática (HTML + CSS + JavaScript, sin dependencias ni compilación).

## Publicar en Vercel
1. Sube esta carpeta a un repositorio de GitHub.
2. En vercel.com → Add New → Project → importa el repositorio.
3. Framework Preset: **Other**. Sin comando de build. Output: la raíz.
4. Deploy.

## Notas
- Los datos se guardan en el navegador de cada visitante (localStorage).
- Pulsa «Explorar con datos de demostración» la primera vez.
- El asistente IA solo funciona dentro de claude.ai.
